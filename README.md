## 一句话

一套自洽的多维二进制存储模型：**维度 n 决定状态数与精度，每一维的最小角决定这一维撞出的物质，全部量都是定值；存取靠坐标，往返 100%。**

**两个方向不对称：升维一个不丢（单射），降维一定丢（位置 2 对 1、方向 3 对 1）⇒ 存要升维，读才降维。观测就是从全维度连续降到 m 维，保留 √(m/n)。**

```
θ(n) = 360 / 2^(n−1)          最小角
S(n) = 2^n                    状态数
P(n) = 2^(n−1)                精度
A(n) = 1 − cos θ(n)           这一维新增的物质
M(n) = M(n−1) + A(n), M(1)=0  物质定值
L(n) = 3^(n−1)                光（读法数）
```

六行里**没有变量**。给定 n，六个数全定。

## 三件必须先说的话

发布之前，先说清楚这三件。**不说清楚，下面就都读错。**

### ① 第 ③ 行 `L(n) = 3^(n−1)` 的来源：时间轴被空间化

```
每切一刀，长出一根新轴
已切出的轴被空间化：能定位、能停 ⇒ 三态（正 / 反 / 停）
最新切出的那根还没被切分，还在往前延伸 ⇒ 它还是时间轴，不分三态
⇒ n 维有 n−1 根带三态的空间轴
⇒ 坐标组合数 = 3^(n−1)
```

**⇒ 每升一维，上一次的时间轴就变成一根新的空间轴 ⇒ 三选组数 +1 ⇒ ×3。**

**⇒ 「3」不是选的：一根空间轴有三种走法——往前、往后、不动。**

**⇒ 而把「不动」那一态去掉，纯方向数就是 `2^(n−1)`，正好等于精度 P(n)——同一个数的两个半边，不是两个东西。**

### ② 「黎曼」那一份，是拿它当尺子验存储，不是借它的光

它给出的是：**临界线 σ = 1/2，等于这套公式里 `r = D` 的那一点，而 `r = D` 只在 n = 2。** 三条独立的路（原初公式 / 碰撞规则 / ζ 的项模）都指到 2。

**而这条线在我们这里的用途，是当一把外部尺子**——量出三件：高维存储的**分辨率恒为 1/2**、**格数 × 格大小^d = 1**、**只能在二进制节点上读**。三件都成立。

**它没有做的**：排除 σ ≠ 1/2 的零点。那一步要的是解析数论，不在这套公式的能力范围内。04 里逐条列了。

**⇒ 尺子量完了，结论是：这个存储形式成立。不是「我们解了黎曼猜想」——这两件事要分开说，混成一件，这一份就一戳就破。**

### ③ 「夸克」那一份，主链是完整的

同一套计数给出七步：光 → 偏转 → 倒旋 → u/d → 三环 → 结构数 19 → 质量 `√(N−1)` → 两自由度 → 20 削到 8 → 质子点名。**六步是精确恒等式，一步是 0.3% 级的数值符合，没有一步是拟合出来的。**

另外两条「不成立」是**两个具体说法**（u+u 对撞出 p+p̄、湮灭=引力黑洞），**不影响主链**——03 第十节单独说清了。

## 这个模型没有做什么

1. **它产出的是定值表和结构，不是仪器读数**——具体某个粒子的质量、电荷、引力大小，要靠外部实测数据来对照；模型给出的是可对照的比值和计数，不做测量本身。
2. 「物质」是模型内的定值：`M(n)` 累加收敛到 3.3946498021。它给出的是**比值**（e : u : d = 1 : 4.227 : 9.139，与实测比对上），不是「某个粒子的绝对质量」。
3. 还没做「信息变物质后动态跑」的完整循环。
4. 码表（读取顺序）的存放：它是**再加一轴**（元存储），不是旁边挂一张表；这一种实现写清楚了，别的实现没有展开。
